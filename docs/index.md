# PyleTree

PyleTree is a simple CLI tool for generating directory tree diagrams.

## Install

### From PyPI

```bash
pip install pyletree
```

### Local

```bash
git clone https://github.com/davi-furtado/pyletree.git
cd pyletree
pip install -e .
```

## Quick start

```bash
pyletree [ROOT_DIR]
```

If no directory is provided, the current directory is used:

```bash
pyletree
```
